# APIStudio

**Create playable 2D, Pixel, and 3D (WebGL / Three.js) HTML5 games & apps directly on Android using AI.**

## Download Latest APK
👉 **[Download APIStudio for Android (Latest Release)](https://github.com/SixthD/APIStudio/releases/latest)**

## Features
- **Bring Your Own API Key (BYOK):** Supports **Google Gemini** (free tier available to test), **OpenAI**, and **Anthropic Claude**. Your keys stay stored locally on your device.
- **2D, Pixel & 3D Modes:** Build games and interactive apps with custom visual styles and Portrait / Landscape previews.
- **Live Preview & Iteration:** Play directly inside the app and refine projects step by step.
- **ZIP & Standalone APK Export:** Export your creations as HTML5 ZIP files or standalone Android APKs.
- **Background Builds:** Switch apps while builds run in your notification shade.

## Play Protect Install Note
Because APIStudio is distributed outside the Play Store and includes a local APK packager and background build service, Google Play Protect may flag the APK as unrecognized.
- Tap **More details → Install anyway** when installing.
- If the option does not appear, temporarily pause **Play Protect** in Google Play Store settings during install, then re-enable it afterward.
